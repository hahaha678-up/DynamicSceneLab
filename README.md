# DynamicSceneLab

**动态场景构建 · 生成式人物轨迹 · 导航闭环评测 · 参数化场景扩增**

面向室内移动机器人的动态环境测试，构建从高保真场景、人物行为生成到导航交互与风险评测的完整流程。系统结合 3DGS / Mesh 场景、Isaac Sim 和 Nav2，将人物运动转化为可执行、可评测、可扩增的机器人测试场景。

## 核心能力

### 高保真动态场景构建

结合 3DGS 场景外观、Mesh / PhysX 物理几何与 LHM 动态人物，组织房间、机器人和多个人物的统一坐标与运动状态，支持第三人称和机器人视角的场景呈现。

### 生成式人物场景

将房间俯视图、可行走区域和尺度信息输入 CrowdES 预训练模型，生成不同起点、方向与时序的人物候选轨迹。通过几何与运动检查、坐标和时间转换，把生成结果接入 Isaac 执行，保留轨迹来源与采样信息。

### 感知—规划—控制闭环

动态人物进入模拟 LiDAR 和局部 Costmap，由 Nav2 输出控制指令驱动 Carter，形成减速、停车、恢复导航等交互响应。支持 Crossing、Occlusion、HuNav 社会力交互与指定轨迹回放。

### 交互评测与场景扩增

统一记录目标到达、最小代理间隙、TTC、制动和停车时间，检查回合数据质量。围绕同一父轨迹，通过时间偏移与速度缩放构造不同冲突强度的变体，保存父子关系与配置，支持重复测试和结果对比。

## 系统流程

```text
3DGS / Mesh 房间 + 人物场景配置
                 ↓
    参数化事件 / CrowdES 候选轨迹
                 ↓
       有效性检查与坐标时间转换
                 ↓
  Isaac 仿真 ↔ LiDAR / ROS2 / Nav2
                 ↓
      回合记录 → 交互指标与结果
                 ↓
    父轨迹 + 时间 / 速度参数 → 变体回测
```

## 场景变体对比

保持人物空间轨迹主体不变，配置三组时间与速度参数，生成不同交互条件。以下三个回合均到达导航目标：

| 变体 | 时间偏移 | 速度倍率 | 最小代理间隙 |
|---|---:|---:|---:|
| 视频 A | +0.8 s | 1.15 | 0.258 m |
| 视频 B | 0.0 s | 1.00 | 0.158 m |
| 视频 C | −1.2 s | 0.80 | −0.378 m |

间隙采用二维圆形代理计算，负值表示代理重叠。配置、视频标签对应关系与实际记录见 [示例数据](examples/README.md) 和 [回合结果](examples/results.json)；指标定义见 [评测说明](hunav-core/crossing/EPISODE_EVALUATOR.md)。
